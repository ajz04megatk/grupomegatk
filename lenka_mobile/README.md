# Lenka Mobile

Aplicacion Flutter para clientes de Inversiones Lenka.

La app consumira exclusivamente la API segura del modulo Odoo `lenka_financiero`.
No replica calculos financieros: Odoo sigue siendo la fuente oficial de saldos,
intereses, cuotas, inversiones y estados de cuenta.

## Estado
- Proyecto Flutter independiente iniciado.
- Backend Odoo y API movil desarrollados en la rama lenka-pilot.
- Proximo bloque: autenticacion y dashboard conectado al ambiente piloto.
